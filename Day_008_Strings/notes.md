# Day 008 - Strings

A string is a sequence of characters enclosed in quotes.

## Examples

```python
name = "Bhushan"
city = 'Bengaluru'
```

## String Length

```python
name = "Bhushan"

print(len(name))
```

Output:

```text
7
```

## String Concatenation

```python
first_name = "Bhushan"
last_name = "More"

print(first_name + " " + last_name)
```

Output:

```text
Bhushan More
```

## String Repetition

```python
print("Python " * 3)
```

Output:

```text
Python Python Python
```

## Key Takeaways

✅ Strings store text

✅ Strings use single or double quotes

✅ len() returns string length

✅ + joins strings

✅ * repeats strings
