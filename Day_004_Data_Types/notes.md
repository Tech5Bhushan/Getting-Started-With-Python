# Day 004 - Data Types

Data types define the type of value stored in a variable.

## Common Data Types

### String

```python
name = "Raghav"
```

### Integer

```python
age = 20
```

### Float

```python
height = 5.9
```

### Boolean

```python
is_learning = True
```

## Checking Data Types

```python
print(type(name))
```

Output:

```text
<class 'str'>
```

## Key Takeaways

✅ str → Text

✅ int → Whole Numbers

✅ float → Decimal Numbers

✅ bool → True or False

✅ type() checks the data type
