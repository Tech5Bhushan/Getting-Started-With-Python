# Day 009 - String Indexing and Slicing

Strings are sequences of characters.

## Indexing

```python
name = "Python"

print(name[0])
```

Output:

```text
P
```

## Negative Indexing

```python
print(name[-1])
```

Output:

```text
n
```

## Slicing

```python
print(name[0:3])
```

Output:

```text
Pyt
```

## Examples

```python
name = "Python"

print(name[:4])
print(name[3:])
```

Output:

```text
Pyth
hon
```

## Key Takeaways

✅ Index starts at 0

✅ Negative indexing starts from the end

✅ Slicing extracts part of a string

✅ End index is excluded

✅ Useful for text processing and automation
