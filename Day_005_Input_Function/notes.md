# Day 005 - Input Function

The `input()` function allows users to enter data during program execution.

## Syntax

```python
input("Enter value: ")
```

## Example

```python
name = input("Enter your name: ")
print("Hello,", name)
```

Input:

```text
RAM
```

Output:

```text
Hello, RAM
```

## Important

`input()` always returns data as a string.

Example:

```python
age = input("Enter your age: ")
```

If the user enters:

```text
20
```

Python stores:

```python
"20"
```

## Key Takeaways

✅ Makes programs interactive

✅ Accepts keyboard input

✅ Returns string data by default
